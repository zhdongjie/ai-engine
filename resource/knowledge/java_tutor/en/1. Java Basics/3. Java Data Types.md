## **Java Data Types**

**Variables** are requesting memory to store values. That is, when creating a variable, you need to request space in memory.

The memory management system allocates storage space to variables based on their type, and the allocated space can only be used to store that type of data.

By defining different types of variables, integers, decimals, or characters can be stored in memory. Java's two big data types: **built-in data types** and **reference data types**.

### 3.1 Built-in data types

The Java language provides eight **basic types**. Six number types (four integer types, two floating-point types), one character type, and one Boolean type.

byte (data type 8 bits, default value 0)

short (data type 16 bits, default value 0)

int (data type 32 bits, default value 0)

long (data type 64 bits, default value 0L)

float(The data type is single-precision, 32-bit, default is 0.0f)

double (data type is double, 64 bits, default value is 0.0d)

char( type is a single 16-bit Unicode character, default is 'u0000')

boolean(data type represents one-digit information; There are only two values: true and false; This type only serves as a flag to record true/false cases; The default value is false; ）

### 3.2 Reference Data Types

The reference type points to an object, and the variable pointing to the object is the reference variable. These variables are specified as a specific type when declared, such as Employee, Puppy, etc. Once a variable is declared, the type cannot be changed.

Objects and arrays are reference data types.

The default value for all reference types is null.

A reference variable can be used to reference any type that is compatible with it.

Example: Site site = new Site("Runoob").

### 3.3 Java Variables

Constants cannot be modified while the program is running.

Use the final keyword in Java to modify constants, declaring them similarly to variables:

```java
final double PI = 3.1415927;
```

Although constant names can also be lowercase, constants are often denoted in capital letters for ease of identification.

### 3.4 Automatic Type Conversion

**Integer, real (constant), and character data can be mixed. In the operation, different types of data are first converted to the same type, and then the operation is performed**.

Conversion from low to high.

```java
Low ------------------------------------> High
byte,short,char—> int —> long—> float —> double 
```

Data type conversion must meet the following rules:

1.  You can't type convert a boolean type.

2.  You cannot convert an object type to an object of an unrelated class.

3.  You must use forced type conversion when converting a type with a large capacity to a type with a small capacity.

4.  Spillage or loss of accuracy can occur during the conversion process, such as:

```java
    int i =128;  
    byte b = (byte)i;
```

```
Because the byte type is 8 bits and the maximum value is 127, when an int is cast to a byte type, a value of 128 will cause an overflow.
```

5. The floating-point to integer conversion is obtained by discarding decimals instead of rounding, for example:

```java
(int)23.7 == 23;        
(int)-45.89f == -45
```

**Automatic type conversion**

For example, if the number of bits in the short data type is 16, it can automatically convert to an int type with 32 bits, and if the number of bits in the float data type is 32, it can be automatically converted to a 64-bit double type.
